# Where to Start: Free Resources for Learning JavaScript

All of these are free. For a 1-month plan, pick one main resource and two helpers.

---

## Best Starting Combo

### Main: The Odin Project (Foundations, then the JavaScript path)
- **Why:** it teaches you to read docs and get unstuck, and it gives you real projects (Rock Paper Scissors, Etch-a-Sketch, Calculator) that match the roadmap.
- **Catch:** it's slow and reading-heavy, and it won't hold your hand. Don't try to finish it in 30 days. Use it for the lessons and projects that match each week.

### Helper 1: javascript.info
- **Why:** it explains *why* JavaScript behaves the way it does, with small exercises after each topic. It's the best free resource for real understanding.
- **Use it when:** an Odin lesson doesn't click.

### Helper 2: freeCodeCamp
- **Why:** the interactive lessons run in the browser, so you start coding in minute one. They're good for the repetition that builds syntax muscle memory.
- **Catch:** the exercises are small and guided, so you still need to build your own projects to learn properly.

---

## YouTube (for a visual overview, not as your main course)

- **freeCodeCamp's YouTube channel:** free full-length JavaScript, React, and Node courses, several hours each.
- **Traversy Media:** "JavaScript Crash Course for Beginners" gives you the big picture in about 90 minutes.
- **Web Dev Simplified:** short, clear explanations of single concepts.
- **Kevin Powell:** the best free CSS teacher on YouTube.
- **Fireship (100 Seconds videos):** quick and fun, but not a course.

Watch a video to get the idea, then close it and build the thing yourself.

---

## What About W3Schools?

It's fine for a quick syntax lookup, but it's shallow and doesn't teach you to build. For lookups, use **MDN Web Docs** (developer.mozilla.org) instead. It's more accurate and more thorough, and you'll need to be comfortable with it as a developer anyway.

---

## How to Use Them Together

| Need | Use |
|---|---|
| Daily lessons and projects | The Odin Project |
| Something didn't make sense | javascript.info, then MDN |
| Extra practice reps | freeCodeCamp |
| Big-picture overview before a new topic | One YouTube video from the list |
| Quick syntax lookup | MDN |

Stick with this set for the full 30 days. Switching resources midway feels productive, but it mostly wastes time.

---

## Day 1 Suggestion

Start with **Odin's Foundations** (command line, Git, and your first HTML page), plus one Traversy crash course if you want a quick overview of JavaScript.
